# User guide (MVP)
1. Sign up, accept acceptable-use terms.
2. Create project with research purpose (min 10 chars).
3. Brief builder: describe organisations/businesses + public contacts. Validator rewrites individual framings.
4. Run search (CSV import, user URLs, registry fixture, map API with key).
5. Review candidates, approve/reject.
6. Export CSV through export gate; cover sheet includes purpose/sources/jurisdictions/retention.
7. Honour opt-outs; records expire at retention date.
