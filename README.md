# Global Contact Research Platform (MVP)
See docs/product-bible.md + docs/implementation-plan.md.

## Quickstart
\`\`\`bash
npm install
npm test
npm run dev:web
\`\`\`
Env: copy .env.example to .env. Postgres schema in packages/db/src/schema.sql; dev uses in-memory store.
Phases: 1 Foundations, 2 Compliance core, 3 Sources/extraction, 4 Export/MVP, 5 Global expansion.
Human responsibilities: counsel review, regulator registration, source terms approval, launch approval.
